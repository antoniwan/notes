## What it is

Values are easy to list and hard to live. A habits audit closes the gap with six questions:

1. Are my daily habits reflecting this value?
2. How much do I have to change?
3. Am I willing and able to commit to the changes?
4. Which habits need to be added?
5. Which habits need to be removed?
6. Which habits need to be improved?

Answered honestly and regularly, it turns values into a continuous improvement plan.

## How it shows up for me

The first time I did it, in 2024, my answer to question one was "hell, no, they did not." That was the useful part. Answering truthfully takes accountability, honesty, humility and some vulnerability.
